# Under the Radar — инструкция

## Требования

- Node.js 22 или новее.
- Steam Web API key для синхронизации каталога.
- Доступ к Steam API из сети.

## Запуск приложения

В папке проекта выполните:

```powershell
node server.js
```

Откройте в браузере: `http://localhost:3000`.

Если порт 3000 занят:

```powershell
$env:PORT=3001
node server.js
```

## Настройка Steam API key

Не записывайте ключ в файлы проекта. Перед запуском синхронизации задайте его в текущем окне PowerShell:

```powershell
$env:STEAM_API_KEY="ВАШ_API_KEY"
```

Переменная действует только в открытом окне PowerShell. При новом запуске её нужно задать снова.

## Синхронизация базы

База хранится в файле `steam-games.db`.

Добавить игры, которых ещё нет в БД:

```powershell
node sync.js add
```

Обновить только уже существующие записи:

```powershell
node sync.js update
```

Если режим не указан, используется `update`.

Для каждой игры синхронизация получает:

- название;
- дату релиза;
- количество отзывов;
- процент положительных отзывов.

## Тестовый запуск

Чтобы обработать только первые 100 игр:

```powershell
$env:LIMIT=100
node sync.js add
```

Количество одновременных запросов можно изменить:

```powershell
Смещение при загрузке
$env:START_OFFSET=0 
$env:LIMIT=100
$env:CONCURRENCY=1
$env:DELAY_MS=4000
node sync.js update
```

Рекомендуемый диапазон — 10–20. Слишком большое значение может привести к ограничению Steam API.

## Поиск в приложении

Поиск выполняется только по локальной БД — после синхронизации приложение не обращается к Steam API.

- Пустое поле поиска — все игры из БД.
- Поле с текстом — поиск по названию.
- Можно задать диапазон количества отзывов.
- Можно задать диапазон процента положительных отзывов.

## Если появляется EADDRINUSE

Это означает, что сервер уже запущен на порту 3000. Используйте уже открытый адрес `http://localhost:3000` или завершите старый процесс:

```powershell
Get-Process node | Stop-Process -Force
node server.js
```
